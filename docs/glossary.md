# Glossary

| Term | Meaning |
|---|---|
| ADR | Architecture decision record |
| Analog / reference class | Similar past programs used for base rates (same target, pathway, indication, modality) |
| `as_of` | Date filter for time-travel: only evidence published up to this date is used |
| Basis | Label of a claim: extracted, derived, inferred, modeled, hypothesis, unknown |
| BICR | Blinded independent central review of imaging endpoints |
| BLA / NDA | Biologics license application / new drug application |
| Breakthrough Therapy (BTD) | FDA designation intended to speed development of drugs for serious conditions |
| Bundle (SoT bundle) | Frozen, content-hashed set of fetched documents for one run; the "source of truth" for reasoning |
| Chair | Reasoning step that lists critical unknowns and requests targeted second-round collection |
| Closed world | Reasoning step sees only the bundle; absence means unknown, not false |
| CMC | Chemistry, manufacturing and controls |
| COGS | Cost of goods sold |
| Critical unknown | An open question that could flip the verdict |
| DCR | Disease control rate |
| Diligence question | A question the public data cannot answer, with the data type that would |
| Entailment | Whether a quote actually supports a claim |
| Evidence | A single fact from a source, with quote, URL, date and level |
| FTO | Freedom to operate |
| Gate | A kill criterion that caps or sets the verdict |
| KOL | Key opinion leader |
| LOA | Likelihood of approval (from a given phase) |
| MSI-H / dMMR | Microsatellite instability-high / mismatch repair deficient tumors |
| NSCLC | Non-small cell lung cancer |
| ODD | Orphan drug designation |
| ORR | Objective response rate |
| OS | Overall survival |
| PFS | Progression-free survival |
| PK/PD | Pharmacokinetics / pharmacodynamics |
| PoS (PTRS) | Probability of (technical and regulatory) success |
| rNPV | Risk-adjusted net present value |
| SoC | Standard of care |
| Target engagement | Evidence that the drug binds and modulates its target in the relevant tissue |
| TAM | Total addressable market |
| Therapeutic window | Range between effective and unacceptably toxic exposure |
| Time-travel | Replaying a run with an earlier `as_of` date |
| TPP | Target product profile |
| Translation chain | Molecular effect, human exposure, target engagement, biological response, patient benefit |
| VoI | Value of information: how much an answer would change the decision |
